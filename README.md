# STRINGS

Official site for STRINGS, a music drama from Scary Romantic. Static HTML, CSS, and JavaScript, served by GitHub Pages.

Site: https://www.stringsofficial.com/

Paths are relative. `CNAME` is `www.stringsofficial.com`. Canonical, Open Graph, Twitter, sitemap, and robots URLs use https://www.stringsofficial.com.

## Preview

```bash
python3 -m http.server 8765
```

## Check

```bash
python3 scripts/check_site.py
```
